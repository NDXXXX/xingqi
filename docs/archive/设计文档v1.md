# Desktop AI Companion 项目设计文档

## 1. 项目目标

开发一个支持 **macOS  的桌面端 AI Companion / Personal Agent。

核心能力：

- 桌面端 AI 对话
- 多 AI 模型切换
- 长期记忆
- 自定义 AI 角色
- Skills
- MCP
- Tool Calling
- QQ 接入
- 后续支持企业微信等聊天渠道
- 所有渠道共享同一个 Agent、Memory 和 Skills

项目不是简单的 AI Chat 客户端，而是：

> 一个运行在电脑上的 Personal AI Agent，并能够通过 QQ 等聊天渠道与用户交互。

# 9. LLM Router

禁止 Agent 直接调用某个模型 SDK。

统一经过：

```text
Agent
 ↓
LLM Router
 ↓
Provider
 ↓
Model
```

调用方式：

```python
provider = provider_router.get_provider(
    provider_name
)

response = await provider.chat(
    messages=messages,
    tools=tools,
    model=model_name,
)
```

这样切换：

```text
DeepSeek
→
MiniMax
→
Kimi
```

Agent 层不需要修改代码。

# 37. 开发原则

Codex 开发时遵守：

```text
1. Agent 与 UI 解耦。

2. Agent 与 Channel 解耦。

3. Agent 与具体 LLM Provider 解耦。

4. 所有 Provider 必须实现统一接口。

5. QQ 只能作为 Channel Adapter。

6. Memory 与 Conversation 分离。

7. Skill 与 Tool 分离。

8. MCP Tool 统一注册到 Tool Registry。

9. 第一版只实现 Single Agent。

10. 每完成一个 Phase 保证当前项目可以正常运行。

11. 不提前开发后续 Phase 的复杂功能。

12. 每个核心模块编写基本测试。

13. Secret 不允许写入源码。

14. 所有异常必须捕获并记录日志。

15. 保持模块化，方便未来继续增加 Provider 和 Channel。
```
