## 2. Application 最终保留清单

完成本批后，`src/zhiyu/application/` 只保留以下跨功能流程和应用级组装文件：

| 文件 | 保留理由 |
| --- | --- |
| `src/zhiyu/application/__init__.py` | 包初始化 |
| `src/zhiyu/application/assistant_profile.py` | 本机助手配置与记忆文件/初始资料协同；实施前确认其跨配置和 Memory 的边界，不把它当 Memory CRUD 服务 |
| `src/zhiyu/application/data_archive.py` | 跨角色、会话、设置等数据的归档与恢复流程 |
| `src/zhiyu/application/doctor.py` | 跨模块本机诊断与修复建议汇总 |
| `src/zhiyu/application/runtime.py` | 应用启动、后台任务和渠道运行时组装 |

本批结束时下列应用文件必须已迁出，不应作为兼容壳继续留在 `application/`：`channels.py`、`characters.py`、`consolidation_jobs.py`、`inbound.py`、`mcp.py`、`memory_jobs.py`、`memory_lifecycle.py`、`memory_queries.py`、`memory_shared.py`、`providers.py`、`scheduled_task_jobs.py`、`scheduled_tasks.py`、`skills.py`。`characters.py`、`providers.py` 和所有列出的记忆实现文件在前序批次迁移。`memories.py` 是既有 MemoryService 兼容入口，按总设计第 8 节留在原路径并只保留必要导出。

若实施时发现 `assistant_profile.py` 或上述任一文件的实际调用已改变，先更新归属说明，再移动；不允许只因文件名而推断职责。

- QQ 主人权限、群白名单、@ 规则、Token、消息去重、断线恢复和反向 WebSocket 关闭顺序不得改变。
