# PRD V1.3 会后确认补充

确认日期：2026-10-10

本文件记录 PRD V1.3 之后确认的范围和语义，作为原 PRD 的补充，不覆盖原文其他需求。

1. **跨角色用户信息**：不同角色共享用户事实与偏好；角色专属的共同经历、剧情和关系状态仍各自隔离。
2. **渠道角色范围**：Web 可切换多个角色；CLI 和现有 QQ 接入继续使用默认助手，暂不增加渠道内的多角色选择。
3. **工具范围**：当前阶段不新增 Agent 工具能力；仓库已有工具、Skills/MCP 保持现状，不因本决定移除。
4. **本地模型地址**：支持用户配置本机和局域网内的兼容推理服务地址。
5. **删除角色**：删除角色时同时删除该角色关联的会话、记忆及其他角色专属数据；跨角色共享的用户信息保留。
